# AI-TOOLS

Collection of AI-related tools, runners, and utilities — primarily for enhancing the **Grok CLI** experience and other AI agent integrations on Windows.

## Projects

- [grok-runner](./grok-runner) - Persistent external command runner for the Grok Build TUI / CLI. Enables reliable execution of batch files and long-running commands from within Grok sessions.

Each subfolder is a self-contained project.
